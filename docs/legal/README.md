# Legal documents — DRAFT INPUTS, NOT LEGAL ADVICE

These files describe what Dynorex actually does with data, so a lawyer can write the real documents quickly
and accurately. They are not ready to publish. Publish the reviewed versions at stable https URLs and set
`EXPO_PUBLIC_TERMS_URL`, `EXPO_PUBLIC_PRIVACY_URL`, `EXPO_PUBLIC_GUIDELINES_URL`, `EXPO_PUBLIC_AFFILIATE_URL`
(the app links them from Settings › About and the paywall; `npm run preflight` blocks release without them).

- `privacy-facts.md` — data inventory: what, why, where, how long, who processes it
- `community-guidelines.md` — draft rules that match the report reasons in the app
- `terms-outline.md` — topics the terms must cover, with the app behaviour each depends on
