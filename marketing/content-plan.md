# Content plan (pre-launch, lean)

Written 2026-11-11 with the `content-strategy` skill. Reads `.agents/product-marketing.md`. No keyword tool or
search-volume data was used (none connected), so "search potential" below is a judgment from what ranks today, not
a measured number.

## Where content lives until there's a site

`dynorex.app` isn't registered, so there is no blog yet. Until it is:

1. **Owned first:** each piece is written once as a page for the landing site (it goes live with the domain) and
   kept in this repo under `marketing/content/` when drafted.
2. **Rented:** the same piece cut into a carousel and a short video (see [social.md](social.md)).
3. **Borrowed:** honest answers in forums and subreddits when someone asks the exact question, with no link
   unless the rules allow it and it helps the person asking.

Everything points to the waitlist. One flagship piece, reused everywhere, beats a new post per platform.

## What already ranks (checked 2026-11-11)

- "Selling a modified car": CarJourney and G-Dimension (both build-log apps, i.e. competitors) and a dealer blog
  already have "keep your receipts, make a summary document" guides.
- "Document mods for insurance": Progressive, Experian, and broker blogs, all saying "keep receipts and photos".
- "Buying a used Sur-Ron": a UK dealer guide, owner Reddit threads and videos; battery health is the first worry.

The gate: a piece only gets made if it adds something those pages don't. Ours can add **a real template, a sample
record you can open, and a named idea (the proof ladder)**, because the product already makes them.

## Pillars

1. **Selling a modified car, bike or e-moto** (the paid moment; decision stage).
2. **Documenting a build** (owners mid-build and at insurance time; implementation stage).
3. **Buying a used e-moto** (the D-74 test segment; awareness stage).
4. **Building Dynorex** (shareable; only if the family is fine with the founder story being public).

## How to write each piece

- Write 10 titles first, pick one. Use the buyer's own words ("lowballed", "receipts", "is it stolen").
- Every number has a link to its source, or it doesn't go in. No made-up stats or quotes.
- Use the sample record on screen, labelled as sample data.
- End with one call to action: the waitlist (or the template download, which offers the waitlist).
- Never "verified", "certified", "guaranteed"; never use the Carfax name in public pieces.

## Measure

Per piece: waitlist signups it brought (use a different link per piece), template downloads, and the questions
people ask in the comments (those become the next pieces). Write results in the Learnings table.
